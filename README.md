# Cerebra
Taking the Cerebro exerpiment to the next level.

While the Cerebro experiment was intended to be a multiple agent, single HITL, single machine system, and tailored for a specific human interaction level, this experiment is meant to expand on that idea to
- Multiple agents - Just like in Cerebro, there should of course be multiple agents, but the agents should scale dynamically depending on where in the system the bottlenecks are at the moment. It should let you know where your team should be expanding on bandwidth to get more throughput through the system.
- Multiple HITL (Humans-in-the-Loop) - Multiple humans should be interacting with the system. Depending on your expertise and role in your team, you may be interacting with one or more of the agents in the fleet. Also, different agent types will be interacting with different humans (roles) through various channels. Interaction in the engine CLI should not be the only way to interact. Depending on preferences, you should be able to interact with your agents using channels like a web page, mail, Slack, Teams, etc.
- Multiple machines - You should be able to scale not just the fleet, but also where the fleet actual run, both to ensure you have enough hardware resources to accommodate for the fleet but also as you may want to use different API keys for different instances.
